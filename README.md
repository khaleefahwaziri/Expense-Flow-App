EXPENSE FLOW APP

Is basically a simple clean SwiftUI expense‑tracking app that helps users record, view, and understand their spending. Built using modern SwiftUI patterns and a state‑driven architecture.
I tried to challenge myself to build this app under 24hrs which was quite fun tbh.

FEATURES INCLUDES

Add & Edit Expenses
• Enter expense name, amount, category, and date
• Clean, intuitive SwiftUI form
• Smooth navigation and state updates
Dashboard Overview
• Summary of total spending
• Category breakdown
• Quick access to recent expenses
Expenses List
• Scrollable list of all recorded expenses
• Easy navigation to edit or delete items
• Simple, readable layout
Charts View
• Visual breakdown of spending by category
• Uses SwiftUI’s declarative UI for clean chart rendering
